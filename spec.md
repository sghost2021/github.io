# My Bio Tool   Personal Bio Website

## Overview
A modern, mobile-responsive personal bio website similar to Linktree that displays a user's profile and social media links in a clean, attractive layout.

## Core Features

### Profile Section
- Display user's profile photo (using provided "Sergio Guillen.jfif")
- Show user's name: "Sergio 'The Nurse'" with enhanced visibility using high-contrast gradient or glow effect
- Display bio text in two centered lines with improved readability:
  1. "Proud to be a nurse. Strong enough to care."
  2. "Haz que las cosas Sucedan. Si se Puede"
- Apply subtle text-shadow or semi-transparent dark overlay behind text section for readability on all devices
- Implement smooth fade-in or slide-up animation for name and bio text for dynamic presentation

### Design Requirements
- Cool 3D live animated background for modern aesthetic
- Vertically centered layout
- Mobile-responsive and touch-friendly design
- Hover animations and smooth transitions for all interactive elements
- Clean, modern visual design
- Enhanced text visibility with high-contrast colors against animated background
- User name styled with gradient or glow effect for prominence
- Bio text with slightly lighter tone than name for hierarchy
- Text shadow or semi-transparent overlay for improved readability
- Smooth fade-in or slide-up animations for text elements
- Bio text lines should be centered and styled consistently with enhanced typography and theme

### Technical Requirements
- All links must open in new browser tabs
- Optimized for mobile devices with appropriate touch targets
- Smooth animations and transitions throughout the interface
- Text animations that enhance readability and visual appeal
- English and Spanish language content support

## Data Storage
No backend data storage required - this is a static personal bio page with hardcoded content and links.
